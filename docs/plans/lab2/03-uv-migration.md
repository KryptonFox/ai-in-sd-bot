# План перехода на uv, включая Docker и CI

Дата: 2026-10-19. Статус: выполнен 2026-10-24; внешние проверки CI и Telegram отмечены ниже.

Самостоятельный подготовительный план для [lab2](04-lab2-implementation.md).
Изменение относительно первоначального плана: зависимости управляются через uv;
requirements и constraints перестают быть источниками конфигурации.
Прикладная логика бота и добавление MCP реализуются отдельным этапом lab2.

## 1. Исходное состояние и результат

На момент подготовки плана в README уже предлагался uv, но `pyproject.toml` не объявляет зависимости,
а `uv.lock` содержит только сам проект. Docker, bootstrap, CI и упаковка для
облачного развёртывания используют requirements/constraints. `httpx` импортируется
кодом, но отсутствует в этих списках; `pydantic` указан только в constraints.

Целевое состояние:

- `pyproject.toml` — прямые зависимости приложения и группа `dev`.
- `uv.lock` — полный зафиксированный граф зависимостей, включённый в Git.
- Python остаётся 3.12; перенос приложения в `src/` и настройка публикации пакета не нужны.
- Локальный запуск, CI и Docker используют один lock-файл.
- Установка зависимостей происходит при подготовке окружения или сборке образа.
