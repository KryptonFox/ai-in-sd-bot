# Использование uv и pyproject.toml

В этом проекте для управления зависимостями, окружением и запуска инструментов используется **`uv`** и стандарт **`pyproject.toml`** (PEP 621).

## 1. Запуск приложения и инструментов
Все команды Python, тесты, линтеры и запуск приложения выполнять через `uv run`:
* **Запуск приложения**: `uv run python -m app`
* **Запуск тестов**: `uv run pytest` (или `uv run pytest -v`)
* **Линтинг и форматирование**: `uv run ruff check .` и `uv run ruff format .`
* **Выполнение скриптов / команд**: `uv run python <script.py>` или `uv run python -c "..."`
* Избегать прямых вызовов `python`, `python3` или `.venv/bin/python`, если доступен `uv run`.

## 2. Управление зависимостями
* Добавление новых пакетов выполнять строго через `uv add`:
  * Основные зависимости: `uv add <package>`
  * Dev-зависимости: `uv add --dev <package>`
* Удаление пакетов: `uv remove <package>`
* Синхронизация окружения: `uv sync`
* `pyproject.toml` и `uv.lock` являются единственными источниками истины для зависимостей проекта. Не использовать прямой `pip install`.
